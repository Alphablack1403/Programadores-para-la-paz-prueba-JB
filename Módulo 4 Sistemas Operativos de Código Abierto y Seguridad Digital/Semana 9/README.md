## Glosario de Conceptos Técnicos
* **Servidor (Server):** Sistema informático (hardware y software) diseñado para ejecutar aplicaciones, procesar datos y responder a las solicitudes o peticiones enviadas por otros computadores denominados clientes a través de una red.
* **Puerto (Port):** Interfaz lógica y numérica que permite a un sistema operativo canalizar de manera organizada el tráfico de red entrante y dirigirlo hacia un proceso o aplicación específica (ej. puerto 3000).
* **Logs (Registros de actividad):** Archivos que almacenan de forma cronológica los eventos, errores, accesos e interacciones que ocurren en un sistema, sirviendo como herramienta clave para el monitoreo y mantenimiento de la estabilidad.
