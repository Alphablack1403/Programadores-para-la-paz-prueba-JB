## Glosario de Conceptos Técnicos
* **Array (Arreglo):** Estructura de datos utilizada en programación para almacenar una colección o lista ordenada de elementos (como objetos, números o cadenas) bajo una única variable.
* **Almacenamiento en Memoria (In-Memory Storage):** Método que guarda datos de forma temporal en la memoria RAM del servidor mientras este se encuentre activo. Los datos se pierden al apagar o reiniciar el servidor.
* **API (Application Programming Interface):** Interfaz estructurada que permite a dos sistemas o aplicaciones independientes intercambiar información y realizar operaciones comunes de manera remota.
