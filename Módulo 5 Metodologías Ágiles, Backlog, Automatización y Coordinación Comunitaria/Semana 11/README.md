## Glosario de Conceptos Técnicos
* **Base de Datos:** Sistema informático estructurado para guardar, modificar, borrar y recuperar grandes volúmenes de datos de manera eficiente.
* **CRUD:** Acrónimo en inglés de Create, Read, Update, Delete (Crear, Leer, Actualizar y Eliminar), que define las operaciones esenciales de manipulación de datos en un sistema.
* **Autenticación:** Proceso de verificación que permite confirmar la identidad digital de un usuario antes de habilitar accesos a vistas o acciones restringidas.
* **Datos Sensibles:** Información privada cuya divulgación inapropiada representa un riesgo para la privacidad e integridad de los usuarios (ej. contraseñas, teléfonos, direcciones).
