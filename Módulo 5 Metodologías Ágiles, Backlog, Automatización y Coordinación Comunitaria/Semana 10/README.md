## Glosario de Conceptos Técnicos
* **Backlog:** Lista priorizada y dinámica de requerimientos, tareas o funcionalidades que necesita un proyecto de desarrollo, sirviendo como guía de trabajo para el equipo.
* **Historia de Usuario:** Explicación breve y sencilla de una funcionalidad del sistema descrita desde la perspectiva del usuario final (quién, qué y para qué).
* **n8n:** Plataforma de automatización de flujos de trabajo basada en nodos y de código abierto que permite conectar diversas APIs y servicios para automatizar tareas repetitivas.
* **Coordinación Comunitaria:** Proceso organizativo apoyado en canales de mensajería (ej. Telegram) y automatizaciones para informar de incidencias y coordinar esfuerzos vecinales de forma ágil.
