## Glosario de Conceptos Técnicos
* **Git:** Sistema de control de versiones distribuido que facilita el rastreo de cambios en el código fuente durante el desarrollo de software, permitiendo la colaboración organizada y transparente entre los miembros de un equipo.
* **Terminal:** Interfaz basada en texto que actúa como intermediaria entre el usuario y el sistema operativo, permitiendo ejecutar comandos directamente sobre el sistema de archivos para automatizar procesos y gestionar recursos de manera eficiente.
