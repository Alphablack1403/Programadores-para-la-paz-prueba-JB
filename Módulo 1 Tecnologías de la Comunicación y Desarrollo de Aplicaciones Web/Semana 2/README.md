## Glosario de Conceptos Técnicos
* **Directorio:** Carpeta virtual dentro del sistema de archivos de una computadora que sirve para organizar, agrupar y almacenar archivos u otros subdirectorios de manera jerárquica y ordenada.
* **Comando:** Instrucción escrita o palabra reservada que se introduce en la terminal para que el sistema operativo la interprete y ejecute una tarea específica sobre el hardware o software.
