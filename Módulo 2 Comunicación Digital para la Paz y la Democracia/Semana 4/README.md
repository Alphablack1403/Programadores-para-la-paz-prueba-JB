## Glosario de Conceptos Técnicos
* **Node.js:** Entorno de ejecución para JavaScript fuera del navegador, construido sobre el motor de JavaScript V8 de Chrome, que permite a los desarrolladores compilar y correr aplicaciones del lado del servidor de forma altamente eficiente y escalable.
* **npm:** Gestor de paquetes oficial para Node.js, que facilita la instalación, actualización y administración de dependencias de código externo de manera organizada y centralizada en un proyecto de desarrollo de software.
* **Express:** Framework web minimalista y flexible desarrollado para Node.js, que proporciona un conjunto robusto de características para estructurar y programar servidores web rápidos, gestionar enrutamientos y procesar solicitudes HTTP.
* **Ruta (Route):** Definición lógica que especifica de qué manera y con qué controlador o recurso debe responder el servidor web cuando un cliente o usuario realiza una petición HTTP a un punto de conexión o URL determinada.
