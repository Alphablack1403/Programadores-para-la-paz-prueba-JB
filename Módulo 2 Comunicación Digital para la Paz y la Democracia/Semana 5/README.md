## Glosario de Conceptos Técnicos
* **API (Application Programming Interface):** Conjunto de reglas y especificaciones estructuradas que permite que diferentes aplicaciones de software se comuniquen, compartan datos y colaboren de manera automatizada entre sí.
* **Endpoint (Punto de conexión):** Dirección URL específica expuesta por una API en la cual el servidor recibe solicitudes de clientes y devuelve la correspondiente respuesta de datos de acuerdo al servicio solicitado.
* **JSON (JavaScript Object Notation):** Formato ligero de almacenamiento e intercambio de datos estructurados, basado en texto plano, fácil de leer y escribir tanto por humanos como por sistemas de software.
* **Métodos HTTP (GET y POST):** Protocolos que definen el tipo de acción que realiza un cliente; GET se utiliza para solicitar y consultar datos del servidor, mientras que POST sirve para enviar o registrar datos nuevos en él.
